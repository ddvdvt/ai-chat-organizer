          Промпты

            Переменные пишите в двойных фигурных скобках: {{тема}}. При вставке расширение спросит их значения.

            Промпты вставляются в поле ввода через панель органайзера на странице чата (вкладка «Промпты»).

            Сайты

            Расширение работает только на включённых сайтах и только с той страницей, которую вы открыли.

            Поиск по открытым чатам

            Когда вы открываете чат, расширение сохраняет его название и текст в этом браузере (IndexedDB), чтобы работали поиск и экспорт из органайзера.

            Расширение не обращается к API сервисов и не скачивает вашу историю: в поиск попадают только чаты, которые вы сами открыли. Ничего не отправляется в интернет.

            Выключите сохранение для любого сайта переключателем выше. Экспорт открытого чата работает и без него.

            Резервная копия

            Папки, теги, закрепления, промпты и настройки — в один файл .json. Тексты чатов в копию не входят: они снова попадут в поиск, когда вы откроете чаты.
