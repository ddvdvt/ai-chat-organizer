# Органайзер ИИ-чатов — папки, поиск, экспорт

**Статус: 1.0.0, готово к отправке в Chrome Web Store.** Тексты карточки, ответы для проверки, скриншоты и промо-картинки лежат в [`store/`](store/). Перед отправкой нужно заменить адрес сайта `BASE` в [`extension/lib/brand.js`](extension/lib/brand.js) и `homepage_url` в манифесте (см. ниже).

> **Важно:** разметка залогиненных страниц сервисов не проверялась вживую (у разработки нет входа в аккаунты). Селекторы написаны по открытым сведениям о разметке и проверены на локальных страницах-имитациях. Что проверить руками — в разделе [«Проверка на живых сайтах»](#проверка-на-живых-сайтах).

Расширение для Chrome/Edge, которое наводит порядок в сотнях чатов с ИИ: папки, закрепление, цветные теги, поиск по тексту чатов и экспорт. Работает с ChatGPT (chatgpt.com), Claude (claude.ai) и Gemini (gemini.google.com). Бесплатно, без аккаунта, всё хранится в вашем браузере.

Чем отличается от соседнего расширения [«Контекст для ИИ»](../ai-context/): то превращает страницы **в промпты**, а это организует и экспортирует **ваши уже существующие чаты**.

## Возможности

- **Папки и подпапки** (один уровень вложенности), **закрепление**, **цветные теги**. Одни папки для всех трёх сервисов.
- **Панель на странице чата.** Справа появляется небольшая кнопка. Панель открывается поверх страницы (закрытый Shadow DOM, разметка сайта не меняется):
  - текущий чат: закрепить, выбрать папку, отметить тегами, экспорт;
  - дерево папок с чатами этого сайта, закреплённые сверху;
  - поиск по открытым чатам этого сайта;
  - библиотека промптов.
- **Перетаскивание.** Чат из списка слева на сайте можно перетащить на папку в панели. При наведении на чат в списке появляется маленькая кнопка «В папку…» с меню.
- **Органайзер** (отдельная вкладка): все чаты трёх сервисов, фильтры по папкам, тегам и сервисам, недавние, «без папки», массовое перемещение, перетаскивание строк на папки, переименование только в органайзере.
- **Локальный поиск по тексту.** Когда вы открываете чат, его название и видимый текст сохраняются в IndexedDB этого браузера. Поиск — по словам и «точным фразам», можно исключить слово через «-слово», найденное подсвечивается. Расширение **не обращается к API сервисов и не выкачивает историю**: в поиск попадают только чаты, которые вы сами открыли. Сохранение отключается для каждого сайта отдельно.
- **Экспорт** открытого чата в **Markdown, HTML, JSON, TXT** и **PDF** (через страницу для печати → «Сохранить как PDF»). Блоки кода сохраняются с языком, таблицы — как GFM-таблицы, формулы — как `$TeX$`. HTML — самостоятельный файл со строгим CSP и без внешних ресурсов. Из органайзера можно скачать сразу много чатов в **.zip** (папки по сервисам).
- **Промпты с переменными** `{{тема}}`: при вставке расширение спрашивает значения и вставляет текст в поле ввода чата.
- **Мягкая деградация.** Селекторы для каждого сервиса лежат в данных ([`extension/config/selectors.json`](extension/config/selectors.json), схема — `selectors.schema.json`). Если сайт поменял разметку, зависящие от неё функции молча отключаются, а во всплывающем окне, панели и органайзере появляется «Сайт изменился, ждём обновления».
- Резервная копия папок, тегов, промптов и настроек в .json. Светлая и тёмная темы, управление с клавиатуры, интерфейс на русском и английском.

## Установка (распакованное расширение)

1. Скачайте или клонируйте репозиторий.
2. Откройте `chrome://extensions` (в Edge — `edge://extensions`) и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное» и выберите папку `extension/`.
4. Нажмите на значок расширения и включите нужные сайты. Браузер спросит разрешение на каждый сайт отдельно.

## Разрешения и зачем они нужны

| Разрешение | Зачем |
|---|---|
| `storage` | Хранить папки, теги, закрепления, промпты и настройки локально (`chrome.storage.local`); передать чат странице печати (`chrome.storage.session`). |
| `scripting` | Подключить скрипт органайзера **только** на сайты, которые вы включили (`registerContentScripts`), и в уже открытые вкладки этих сайтов. |
| `https://chatgpt.com/*`, `https://claude.ai/*`, `https://gemini.google.com/*` — **необязательные** | Запрашиваются по одному, когда вы включаете сайт во всплывающем окне или в настройках. Без них расширение ничего на сайтах не делает. Отозвать можно там же. |

При установке расширение не просит доступа ни к одному сайту. `downloads` не нужен: файлы сохраняются обычной ссылкой «скачать». `unlimitedStorage` не нужен: IndexedDB расширения хватает на тысячи чатов, а индекс восстанавливается сам, если открыть чат. Сетевых запросов нет вообще (единственный `fetch` читает файл `config/selectors.json` из самого расширения).

## Конфиденциальность

Всё хранится только в вашем браузере. Тексты чатов читаются со страницы, которую вы открыли, и только если включено «Запоминать открытые чаты для поиска». Панель живёт в закрытом Shadow DOM, поэтому скрипты сайта не видят ваших папок и чатов других сервисов. Нет аналитики, рекламы и аккаунтов. Подробнее — в [PRIVACY.md](PRIVACY.md).

## Страницы на сайте автора

После установки открывается вкладка `BASE/welcome/ai-chat-organizer.html`, после удаления — `BASE/bye/ai-chat-organizer.html`, ссылка «Другие расширения автора» ведёт на `BASE/#ai-chat-organizer`, а `homepage_url` — на `BASE`. Адрес `BASE` задан в одном месте: [`extension/lib/brand.js`](extension/lib/brand.js) (сейчас там заглушка `https://USER.github.io/REPO/`). После замены поменяйте и `homepage_url` в `extension/manifest.json` — `npm test` проверяет, что они совпадают.

## Проверка на живых сайтах

Локальные страницы в `e2e/fixtures/` повторяют известную структуру сервисов, но вживую селекторы не проверены. Человеку с аккаунтами нужно открыть каждый сервис с включённым расширением и проверить:

1. **Кнопка органайзера** появилась справа, сайт работает как обычно (ввод, отправка, прокрутка).
2. **Индексация:** откройте чат с кодом и таблицей → в органайзере он помечен «в поиске», поиск по слову из ответа находит его.
3. **Экспорт MD** из панели: роли «Вы»/ассистент чередуются правильно, нет лишних слов «Копировать код», язык блока кода указан (```python), таблица — GFM, формулы — `$…$`. Нет дублей сообщений и пропусков.
4. **Название чата** в панели совпадает с названием на сайте (у Gemini берётся из выделенного пункта списка слева).
5. **Наведение** на чат в списке слева показывает кнопку-папку; **перетаскивание** чата из списка на папку в панели работает.
6. **Промпты:** вставка в поле ввода (ProseMirror у ChatGPT/Claude, Quill у Gemini) — текст появляется, кнопка отправки становится активной.
7. **Стриминг:** во время генерации ответа чат не индексируется, после окончания — индексируется один раз.
8. В попапе статус «работает», в органайзере → «Настройки» → «Разметка в порядке».

Если что-то не так — правится только [`selectors.json`](extension/config/selectors.json): списки селекторов пробуются по порядку. Самые вероятные места поломки: `message`/`userMessage` (роли), `content`, `title` у Gemini, `sidebarLink` у Gemini (если пункты списка — не ссылки, перетаскивание и кнопка у списка там работать не будут), `streaming`. Длинные чаты Gemini подгружаются при прокрутке вверх — в индекс попадает то, что отрисовано.

## Разработка

```
npm test               # модульные тесты (node:test): конвертер DOM → Markdown/HTML/текст, извлечение на страницах-имитациях,
                       # папки, поиск, форматы экспорта, промпты, проверки релиза
npm run test:e2e       # смоук-тест в установленном Chromium (playwright-core) на локальных страницах-имитациях
npm run zip            # архив dist/ai-chat-organizer-<версия>.zip с проверкой содержимого
npm run store:images   # скриншоты 1280×800 и промо-картинки в store/ (настоящий интерфейс, локальные страницы)
npm run icons          # перегенерировать иконки
npm run locales        # пересобрать _locales из scripts/locales.src.mjs
```

Устройство кода:

- `extension/lib/` — чистая логика без `chrome.*`:
  - `services.js` — сервисы, хосты, id чатов из URL;
  - `selectors.js` — проверка `selectors.json`, здоровье разметки;
  - `convert.js` — DOM → Markdown / текст / безопасный HTML (белый список тегов);
  - `extract.js` — сообщения, роли, заголовок, ссылки списка чатов;
  - `org.js` — папки, теги, закрепления (редьюсеры);
  - `search.js` — нормализация, запрос, ранжирование, подсветка;
  - `exportfmt.js` — MD/HTML/JSON/TXT, имена файлов, .zip;
  - `prompts.js`, `settings.js`, `backup.js`, `zip.js`, `brand.js`.
- `extension/src/background.js` — единственный писатель данных, регистрация скрипта для включённых сайтов.
- `extension/src/content/` — загрузчик, логика страницы и панель в закрытом Shadow DOM.
- `extension/src/popup/`, `organizer/`, `print/` — страницы расширения; `shared/db.js` — IndexedDB.

Смоук-тест и генератор картинок работают с временной копией расширения (`e2e/harness.mjs`): хосты сервисов заменены на `*.localhost` по http, доступ к ним выдан при установке (окно разрешения нельзя нажать в автоматике), Shadow DOM открыт для Playwright. Само расширение этого не делает.

## Известные ограничения

- Индексируется только отрисованный текст открытого чата. Вложения, изображения (в экспорте — `[image: …]`), холсты и артефакты не сохраняются.
- Если сервис виртуализирует или подгружает длинную ленту частями, в индекс и экспорт попадает то, что сейчас в DOM.
- Перемещение и папки живут только в расширении: на самих сайтах ничего не меняется и не синхронизируется между устройствами.
