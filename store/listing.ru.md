# Карточка в Chrome Web Store — русский

**Язык:** русский (ru). Английский вариант — в `listing.en.md`. Тексты интерфейса берутся из `extension/_locales`.

## Название (из манифеста, 43 символа)

Органайзер ИИ-чатов — папки, поиск, экспорт

Запасной вариант, если модерация придерётся к названию: «Папки и поиск для ИИ-чатов». В названии нет чужих товарных знаков; совместимость с сервисами указана только в описании.

## Краткое описание (из манифеста, 122 символа из 132)

Папки, теги, закрепление и локальный поиск по вашим ИИ-чатам. Экспорт в Markdown, HTML, PDF. Для ChatGPT, Claude и Gemini.

## Категория

Productivity → Tools (Работа → Инструменты)

## Подробное описание

Сотни чатов с ИИ в одном длинном списке — знакомо? Расширение раскладывает их по папкам, находит нужный разговор по тексту и сохраняет его в файл. Бесплатно, без регистрации и без серверов.

Что умеет

• Папки и подпапки, закрепление, цветные теги. Одни и те же папки для ChatGPT, Claude и Gemini.
• Панель прямо на странице чата: положить текущий чат в папку, закрепить, отметить тегом, экспортировать.
• Перетащите чат из списка слева на папку — или нажмите маленькую кнопку, которая появляется при наведении.
• Отдельная вкладка-органайзер: все чаты трёх сервисов, фильтры по папкам, тегам и сервисам, массовое перемещение.
• Поиск по тексту чатов, которые вы открывали: слова, «точные фразы», исключение через минус, подсветка найденного.
• Экспорт в Markdown, HTML, JSON, TXT и PDF. Код сохраняется с языком, таблицы — таблицами, формулы — в TeX.
• Много чатов разом — одним архивом .zip.
• Библиотека промптов с переменными: «Объясни {{тема}} простыми словами» — расширение спросит значение и вставит текст в поле ввода.
• Резервная копия папок и промптов в файл.
• Светлая и тёмная тема, русский и английский интерфейс.

Как пользоваться

1. Нажмите на значок и включите сайты, где вы общаетесь с ИИ. Браузер спросит разрешение на каждый сайт отдельно.
2. Откройте чат — справа появится кнопка органайзера.
3. Создайте папку и перетащите в неё чаты из списка слева.

Приватность

Тексты чатов читаются только со страницы, которую вы сами открыли, и хранятся только в вашем браузере. Расширение не обращается к API сервисов и не скачивает историю. Сохранение для поиска отключается для каждого сайта. Нет рекламы, аналитики и аккаунтов, нет сетевых запросов.

Ограничения

Сервисы иногда меняют разметку. Тогда часть функций временно отключится, а расширение покажет «сайт изменился» — исправление придёт с обновлением. Вложения и изображения не сохраняются. Папки хранятся в браузере и не синхронизируются между устройствами.
